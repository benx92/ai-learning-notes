# 大模型应用开发学习

这是一个面向技术读者的大模型应用开发学习系列，记录从模型调用基础，到语义检索、RAG、工具调用、Agent 和应用编排的学习与实践。

本系列重点回答的是：

> 已经有了一个可调用的大模型，怎样把它接入程序，并逐步构建可以使用、可以验证、可以维护的 AI 应用？

神经网络、训练过程、Transformer、Attention、QKV 等更完整的模型内部原理，放在平级目录 `../llm-foundations` 的“大模型基础原理”系列中单独展开。

## 内容结构

当前32篇主线均已有正文，23—32配有共享售后助手与独立机制实验。相关工具说明放在[supplements](supplements/README.md)，代码与运行方式放在[examples](examples/README.md)。

系列围绕模型调用、Agent运行机制、RAG、LangChain和LangGraph的知识点展开，相近内容合并到具体问题里解释，最后通过一个售后助手完成应用实践。工具库与接口不逐一对应独立文章。

## 案例怎样贯穿

从同一售后场景逐步增加需要：先根据政策回答，再查询订单实时状态，然后接续对话、准备申请并等待确认。流程、按需知识、长任务、后台和协作用小实验解释机制；综合应用复用已有模块，只接入实际任务需要的能力。

23—32的[代码与运行说明](examples/23-32-assistant/README.md)及[下载包](examples/23-32-example.zip)提供政策资料、教学订单、依赖配置、运行命令和正常/失败案例。能够运行、解释每步分工并检查结果，就完成了这条学习路线。真实模型效果、模拟后端与实际业务写入的范围在案例中明确说明。

可以按编号阅读；希望先看到完整知识问答时，完成09后可先读12—13，再回到10—11理解检索优化。工具说明在对应问题出现时阅读，无须先学完所有库。

## 与“大模型基础原理”系列的关系

两个系列是平级关系，不要求必须先读完原理系列才能学习应用开发：

| 系列 | 主要回答的问题 |
| --- | --- |
| 大模型应用开发学习 | 怎样调用、约束和扩展模型，构建真实应用 |
| 大模型基础原理 | 模型为什么能够学习、理解上下文并生成文本 |

应用系列会保留必要的原理直觉，但以帮助工程决策为边界；需要完整推导的内容会链接到基础原理系列。
