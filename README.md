# 大模型应用开发学习

这是一个面向技术读者的大模型应用开发学习系列，记录从模型调用基础，到语义检索、RAG、工具调用、Agent 和应用编排的学习与实践。

本系列重点回答的是：

> 已经有了一个可调用的大模型，怎样把它接入程序，并逐步构建可以使用、可以验证、可以维护的 AI 应用？

神经网络、训练过程、Transformer、Attention、QKV 等更完整的模型内部原理，放在平级目录 `../llm-foundations` 的“大模型基础原理”系列中单独展开。

## 内容结构

- `01-*.md` 到 `24-*.md`：按照当前学习和写作顺序完成的正文文章
- [examples](examples/)：文章配套代码、样例文件、依赖与运行说明
- [supplements](supplements/README.md)：部分章节的实现细节与扩展阅读

## 系列结构

1. 模型认知与调用基础：大模型、Prompt、生成、API、Token
2. 语义检索与 RAG：Embedding、相似度、切分、向量数据库、混合检索、RAG
3. 工具调用与 Agent：Function Calling、ToolCall、MCP、Agent、安全护栏
4. 应用编排与状态管理：LangChain、Runnable、LCEL、结构化输出、Memory
5. AI 开发工程实践：worktree、rich 等辅助开发与调试工具

## 阅读建议

第一次接触大模型应用开发，可以从 `01-我先把大模型是什么这件事想明白.md` 开始，顺着编号阅读。

已经具备模型调用经验的读者，也可以直接从感兴趣的阶段进入：

- 想做知识库问答：从第 06 篇 Embedding 开始
- 想让模型调用工具：从第 15 篇 Function Calling 和 ToolCall 开始
- 想了解应用框架和状态管理：从第 19 篇 LangChain 开始

## 与“大模型基础原理”系列的关系

两个系列是平级关系，不要求必须先读完原理系列才能学习应用开发：

| 系列 | 主要回答的问题 |
| --- | --- |
| 大模型应用开发学习 | 怎样调用、约束和扩展模型，构建真实应用 |
| 大模型基础原理 | 模型为什么能够学习、理解上下文并生成文本 |

应用系列会保留必要的原理直觉，但以帮助工程决策为边界；需要完整推导的内容会链接到基础原理系列。
